# Contributing Policy

Thank you for your interest in **PaperMind AI**!

## 🚫 External Contributions Notice

**Please note that external code contributions, pull requests (PRs), and feature additions are strictly CLOSED.**

This project is actively developed and maintained as a proprietary, single-author research platform by **Dhruv Sharma**. To maintain architectural integrity and licensing requirements, external code contributions are not accepted.

---

## 🐛 Reporting Bugs & Issues

While pull requests are closed, feedback and bug reports are warmly welcomed:

1. **Check Existing Issues**: Search the GitHub Issues tab to ensure your issue hasn't already been reported.
2. **Submit a Bug Report**: Open a new issue including:
   - Clear description of the problem
   - Minimal steps to reproduce the issue
   - Expected vs actual behavior
   - Python version, operating system, and LLM provider used
   - Tracebacks or error logs (sanitizing any API keys)

---

## 💡 Feature Suggestions

If you have architectural ideas or feature suggestions for the upcoming **v2.0 Roadmap**, feel free to open a discussion or feature request issue under the **Issues** tab.

Thank you for understanding!
